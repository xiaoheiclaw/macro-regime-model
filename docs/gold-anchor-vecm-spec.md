# 黄金"锚 + 偏离"模型:可检验设定

> 缘起:Baur (2013) 的变化回归得出利率对金价≈0,但他的模型**没有锚项**——只有 Δ对Δ 的同期相关。用户的直觉是:金价有一条由"法币/债务存量"决定的**基准线(锚)**,实利率驱动的是金价**对这条锚的偏离**。这正是协整 + 误差修正(VECM)。本文把它写成一个能跑、能被证伪的设定。
>
> 核心赌注(推理):**Baur 的利率≈0 是因为漏了误差修正项(ECT)。一旦把锚放进去,实利率应在"偏离"那一项里现形。** 这条若成立,"长端是锚、短端≈0"的口径矛盾就消解了——两者分别活在长期协整向量和短期 ECM 里。

## 0. 变量与口径

频率:月度(债务/货币锚)。区间:1971–2025(布雷顿森林解体后浮动金价起)。

| 角色 | 符号 | 候选序列 | FRED/来源 |
|---|---|---|---|
| 被解释 | G | ln(名义金价 USD/oz) | LBMA `GOLDAMGBD228NLBM` |
| **锚候选(三选一,别堆)** | A | ln(美债总额/GDP) | `GFDEBTN` / `GDP` |
| | | ln(美联储总资产/GDP) | `WALCL`(仅 2008+,样本短,慎用) |
| | | ln(M2/GDP) 或 ln(基础货币/GDP) | `M2SL` / `BOGMBASE` |
| **偏离驱动** | r | 长端实利率(10y TIPS) | `DFII10`(2003+,见下注) |
| 偏离控制 | — | 实际广义美元指数 | `RTWEXBGS` |
| | | 地缘风险 GPR / VIX | Caldara-Iacoviello GPR |
| | | 央行净购金(季,2010+) | WGC Gold Demand Trends |

口径注记(事实):
- 金价用**名义**,价格水平交给 CPI/锚吸收;不预先 deflate(避免引入实利率自身的通胀分量产生内生)。
- 实利率口径修正(事实):FRED `DFII10`(10y 不变期限 TIPS 实际收益率)实际起点是 **2003-01**,**不是 1997**——TIPS 自 1997 发行,但 10y 不变期限序列 DFII10 自 2003 才有。要 1997 起的样本需改用其它 TIPS / 实利率 proxy(如单券 TIPS 或 Cleveland Fed 实利率)。本实现的全样本走**拼接**:2003 前用 `10y 名义(GS10) − 已实现 12m CPI 通胀`,2003 起接 DFII10,拼接断点标注在案(已知弱点)。
- 锚一律**除以 GDP**。理由(推理):债务/Fed表/M2 的绝对额都是单边猛涨的确定性趋势,直接用会重造"两条上升线碰一起"的伪相关;除以 GDP 才有可能让比值平稳/均值回归。**追本**:贬值机制说的是"法币claims相对真实产出膨胀",分母本就该是产出。

## 1. 第 0 步——单整阶数(决定谁能进协整向量)

对 G、A、r 各跑 ADF + PP + KPSS,levels 与 first-difference 都做。

- 预期(推测):G、A ~ I(1);r 在样本里常处于 I(1)/I(0) 边界。
- **关键分叉**:若 r 被判 I(0)(平稳),它**不能进长期协整向量**,只能进短期 ECM。这恰好对应"实利率是偏离驱动、不是锚"——和用户直觉一致。若 r 是 I(1),它可以同时进长期和短期,需另行解释。
- 全部记录在案,别跳过。

## 2. 第 1 步——长期锚(协整检验)= 真锚还是伪趋势的判决

对系统 [G, A] (若 r 为 I(1) 则加入) 跑 **Johansen**(trace + max-eigen),定协整秩。

- **rank = 0 → 没有锚**:基准线是伪共同趋势,用户的"基准"假说**被证伪**,退回"黄金无稳定锚、只有 regime 依赖驱动"。
- **rank ≥ 1 → 锚成立**:估协整向量 `G = α + β·A (+ θ·r)`。β = 黄金对锚的长期弹性。
  - 预期(推测):纯贬值假说下 **β ≈ 1**(金价随 法币/GDP 等比例重定价)。β 显著偏离 1 要解释。
- 交叉验证:Engle-Granger 双变量协整作旁证;**Gregory-Hansen** 检验协整关系是否在 2008 或 2022 发生**结构断点**(直接回答"2022 是不是锚关系本身变了")。

## 3. 第 2 步——短期偏离动态(ECM / VECM)= 实利率在这里现形

估误差修正方程:

```
ΔG_t = λ·ECT_{t-1} + Σ φ_i ΔG_{t-i} + Σ δ_j Δr_{t-j} + Σ(控制变量) + u_t
ECT_{t-1} = G_{t-1} − α − β·A_{t-1}   # = 金价对锚的偏离(上一期)
```

判读:
- **λ < 0 且显著 = 误差修正**:金价偏离锚后会被拉回。回归速度 |λ|,半衰期 `ln(0.5)/ln(1+λ)`。λ 不显著 → 即便协整也没有真正的"锚定力",存疑。
- **δ(Δ实利率系数)= 用户说的"在基准线上波动"**。
  - **本设定的核心可证伪点(推理)**:Baur 的纯变化回归 δ≈0,是因为他**没有 ECT 项**。加上 ECT 后,若 δ 显著为负 → "实利率驱动金价对锚的偏离"成立,用户假说立住;若 δ 仍≈0 → 实利率连偏离都不驱动 →"长端是锚"彻底死。

## 4. 第 3 步——锚能否解释 2022 断裂

把 2022–2025 金价路径分解成两块:
- **锚贡献** = β·ΔA(债务/GDP 上行 + 若用 Fed 表则缩表反向)
- **偏离贡献** = δ·Δr(实利率转正,应为负) + 控制项(央行购金,2010+ 子样本加入)

- 假设(推测):**锚贡献为正且大(债务扩张 + 央行购金),实利率偏离贡献为负,净正因为锚压过偏离** → "不是断裂,是锚抬高了"。
- 量化两者占比。若 |锚贡献| > |偏离贡献| 且方向如上 → 用户的"锚盖过波动"重述获定量支持。

## 5. 第 4 步——三个锚的赛马(降秩)

债务/GDP、Fed表/GDP、M2/GDP 高度共线(2008、2020 后齐爆),**别合并进同一回归**,横向比:
- 协整强度(Johansen 统计量)
- β 是否接近 1(经济合理性)
- ECT 显著性 λ
- 样本外拟合

挑协整最干净 + 机制最讲得通的那一个当主锚。

## 杀死条件(任一触发即否定或大改)

1. 任何锚都无协整(rank=0)→ "基准"是伪趋势,假说死。
2. 协整成立但 λ(误差修正)不显著 → 无回归力,不算真锚。
3. 加了 ECT 后实利率 δ 仍≈0 → 实利率连偏离都不驱动,"长端是锚"死。
4. β 远离 1 且无机制解释 → 贬值故事存疑,需换框架。

## 下一步落点(能用的动作)

1. 先抓数据(FRED 上述代码 + WGC 央行购金),跑第 0 步定 I(1)/I(0)。
2. 用 `debt/GDP` 当首选主锚(连 Reinhart-Sbrancia 金融抑制那条线 [[paper-debt-liquidation]]),Fed表/M2 当对照。
3. 第 1–2 步出来就能判:用户的"锚+偏离"到底是真结构还是又一个伪相关。
4. 这是钉死"长端是锚"的正路;`Baur (2011)` 与那篇 Markov-Switching VECM 可作方法参照(对照他们的长短端定义)。

> 全文系**待检验设定**,所有预期符号/β≈1/2022 分解均为 (推理)/(推测),跑出来前不作 (事实)。

## 修订(2026-06-28,PR #1 merge 后)— 锚的定义升级为三变量

PR #1 测的是**双变量** `[ln金价, ln(债务/GDP)]` 协整,实利率因被判 I(0) 被踢出长期向量、只当短期偏离驱动。结果:在 AIC 选阶 + lag/det 稳健性网格下,**协整脆弱(rank∈{0,1}、β∈[0.29,1.71])**,不能稳健宣称"债务单锚成立"。

**关键修正(用户提出)**:若实利率本属于长期均衡的一部分,则双变量测试是**漏变量**——测不出协整可能不是"无锚",而是"锚少了一条腿"。锚应定义为**联合长期均衡面**:

```
长期(锚):   ln金价* = α + β₁·ln(债务/GDP) + β₂·(长端实利率)
短期(围着它波动): Δln金价 = λ·ECT_{t-1} + 风险溢价/央行购金/动量 + ...
```

债务把锚往上抬(贬值),实利率把锚往下压(机会成本),两者**共同**定均衡;实利率的长期系数 β₂ 与短期系数是两个不同的数,正是 VECM 要拆开的。"长端是不是锚"= β₂ 是否显著。

**下一步(PR #2)**:
1. 先严格复核**长端实利率**的单整阶(c + ct;且分全样本拼接序列 vs 干净 post-TIPS(DFII10,**2003+**,非 1997)两段——I(0)/I(1) 定性直接决定它能否进协整向量;PR #1 判 I(0) 是它出局主因,存疑需复核)。
2. **三变量 Johansen** `[ln金价, ln(债务/GDP), 实利率]`,复用 PR #1 的 lag/det 稳健性网格,报告 rank 与协整向量 (β₁, β₂)。
3. 若稳健 rank≥1 → **估 VECM**:长期 β₁/β₂ + 短期 ECM(误差修正速度 λ、短期 Δ实利率系数),明确回答"实利率在锚里(β₂ 显著)还是在偏离里(短期显著)还是两者皆有"。
4. 杀死条件不变:三变量仍无稳健协整 → 线性常参数锚(含实利率)证伪,再转 regime-switching/断点协整。

## 修订(2026-06-28,PR #3)— Gregory-Hansen 断点协整:锚是否「分段存在」

PR #2 的结论(事实):三变量 Johansen(clean TIPS ≥2003)`coint_rank∈{0,1}` **随 lag/det 漂移、不稳健**,普通常参数协整仍立不住。这留下一个可证伪的岔口:**测不出协整,是「真没锚」,还是「锚的向量在某个日期发生了位移(常参数检验因此失败)」?**

**PR #3 用 Gregory & Hansen (1996) 残差检验**回答(spec §2 的 GH 交叉验证落地):
- H0 = 无协整;H1 = **允许一个未知断点**(level shift `C` / regime shift `C/S`)的协整。
- 对 (a) 双变量 `[ln金价, ln(债务/GDP)]`(全样本)与 (b) 三变量 `[+实利率]`(clean TIPS ≥2003)都跑 C 与 C/S;内生搜索断点,报 **ADF\*/Zt\*/Zα\*** 与 GH (1996) Table 1 临界值(按 m=回归元个数索引)。
- 断点估计检查是否落在 **2008 / 2022** 附近(直接回答「2022 是不是锚关系本身断了」)。

**运行方式(非硬编码结果)**:`uv run python scripts/gold_anchor_analysis.py --end <asof>` 生成 `analysis/gold_anchor_cointegration_<asof>.md`(`data/`、`analysis/` 不入库,结果随数据 vintage 漂移,故**本规范不冻结具体统计量**;裁决见生成报告 §4)。

**裁决逻辑(预注册,编码在脚本里)**:
- **主判据**:对每个 system×model 单元,「拒绝无协整」当且仅当 **3 个统计量(ADF\*/Zt\*/Zα\*)中 ≥2 个拒绝**(多数决);ADF\* 为头条统计量。单统计量孤立显著只作旁证,不计为结论。
- **完整性门**:杀死条件只在**所有必需 system×model 都成功产出且无一达多数决拒绝**时才触发;有跳过/出错单元 → 结论 inconclusive,不触发。
- **统计口径**:不拒绝 H0 ≠ 证明 H0(无协整)为真——尤其三变量短样本(2003+)GH 断点检验功效有限,「未找到证据」也可能是功效不足。因此**不写成「分段存在被否定 / 线性锚被证伪」**,只写「未找到(单断点)协整证据」。

**杀死条件(§杀死条件,预注册)**:若在预设显著性下、所有设定均**未找到**(常参数 + 单内生断点)协整证据 → 按预注册杀死条件,**暂停常参数 / 单断点线性路线**,转 **Markov-switching / TVP(时变参数协整,PR #4)**。

**如实标注(事实)**:干净 TIPS 仅 2003+,三变量 GH 在短样本上断点检验**功效有限**;且 GH 只允许**单个**断点——「测不出」不能排除多断点/平滑时变带来的协整,故须谨慎解读、转 PR #4 用更柔性的设定复核。
## PR #4(2026-06-28)— 时变锚之一:Markov-switching 回归(离散跳变)

PR #1–#3 否定了所有**线性 / 常参数 / 单断点**锚(双变量、三变量 Johansen、Gregory-Hansen 断点协整全否)。与 Baur (2013)「驱动系数逐十年翻正负」互证 → **锚若存在,系数随 regime 时变,常参数工具按定义抓不住。** PR #4 测第一种时变形式:**离散跳变**——世界在 2–3 个 regime 间跳,每个 regime 一套驱动系数。

**实现**(`lib/gold_anchor.py` + `scripts/gold_anchor_markov.py`):
- 主模型:对**平稳的 Δln金价**(非 I(1) levels,避免伪回归)跑 `statsmodels MarkovRegression`,自变量 [Δln(债务/GDP), Δ实利率],**回归系数与残差方差均 regime 依赖**(`switching_variance=True`)。先 2 态、再 3 态,按 **BIC + 经济可读性**选 K。
- 样本两段(对 spec 的 full-vs-clean 口径):**全样本 1968+** 用 debt-only MS(实利率拼接代理脏);**post-2003** 加干净 TIPS 实利率,做「实利率进 regime」的检验(回答「长端是锚」的 regime 条件版:Δ实利率在**哪些 regime** 显著/量级有别)。
- 报告:每个 regime 的系数表(t/p、显著性)、转移矩阵(列和=1)、各 regime 期望持续期、**平滑 regime 概率时序**(交叉核对 1970s 高通胀 / Volcker / 2008 GFC / 2022 这些已知段能否被自动复现)、年度主导 regime 时序。
- 「regime 区分度」三判据:系数跨 regime **符号翻转** ∨ **仅部分 regime 显著**(regime 条件) ∨ **量级显著有别**(range > 2·SE,同号但配方不同)。三者任一成立即「driver distinct」。
- 重协整版(进阶,本 PR 不做):Markov-switching VECM(Krolzig / Hall-Psaradakis-Sola)让协整向量本身 regime 依赖,计算重。

**坑(如实标注)**:① MS 似然多峰、对初值敏感 → 默认 EM 起点 + 多随机重启(`search_reps`,seeded 可复现,提高 `em_iter`/`maxiter`)取最高似然;② regime 标签不可识别(重排序号似然不变)→ 必须**事后按系数**解释,勿按序号;③ 短样本下 3 态易过拟合 → BIC + 退化门双核;④ 干净实利率仅 2003+,限制「实利率进 regime」检验只在 post-2003。

**退化解硬化(round 2,关键)**:真数据 MS 极易返回**退化解**——某 regime 塌到单个离群点(σ²→0、期望持续≈1 月、系数 |t|~1e13 来自 SE≈0,statsmodels 报 p=0.000 会被误读为「显著」)。本实现:
- **系数显著**须 `|t|<1e6 且 p<α`(|t|>1e6 判**未识别**,不算显著);
- **regime 退化判据** = `σ² < Var(Δln金价)×1e-3` ∨ `期望持续 < 3 月` ∨ 任一系数未识别;
- **K 选择**:含退化 regime 的解作废,取最大「全 non-degenerate」**可信 K**(收敛 + 无退化 + ≥2 non-deg regime);全不可信 → 等价 K=1=**无切换**;
- **区分度 / 「regime 条件锚」** 只在 non-degenerate 且**显著**的 regime 间比较(剔除退化 regime、忽略不显著系数的伪符号翻转);
- 最优解仍未收敛/退化 → 报告如实标「**不可信**」,**不给「获支持」**。

**实证结果(round 2,1968–2025)**:① **full 1968+ debt-only**:可信 K=2(BIC-min K=3 因含退化 regime 作废),两 regime 已收敛、非退化,但只是**低波动/高波动的方差分段**——Δln(债务/GDP) 在两 regime **均不显著**(p=0.35 / 0.72)→ 非「regime 条件锚」。② **post-2003 debt+实利率**:K=2/K=3 **均未收敛 + 含退化 regime**(σ²→0、1 月、|t|~1e13)→ 无可信切换。**裁决:两样本经硬化后均无可信、系数显著有别的 regime 结构 → 连离散时变锚也不成立,延续 PR#1–#3 全否。** (事实/推理)

**杀死条件(PR #4)**:若两样本均找不到可信、系数显著有别的 regime 结构 → **连离散时变锚也不成立**,转 **TVP / Kalman(PR #5)**;若 TVP 也无结构,则黄金「无稳定锚,只剩 regime/叙事」。← 本轮即触发此条。

运行:`uv run python scripts/gold_anchor_markov.py [--start 1968-01-01] [--end YYYY-MM]`,报告写到 `analysis/gold_anchor_markov_<date>.md`,平滑概率与 meta 写到 `data/`。

### PR #5(后续):TVP / Kalman — 平滑漂移
系数走随机游走,Kalman 滤波估 β₁ₜ(债务敏感度)、β₂ₜ(实利率敏感度)的平滑时间路径 + 置信带。与 Markov 对照:漂移是**突跳**(支持 regime)还是**平滑**(支持 TVP)。
